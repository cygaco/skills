# Product Telemetry Knowledge Library

> Deeper references for you and your AI on launch-stage product telemetry. These references keep analytics tied to product learning: activation, funnels, core actions, and verified chain integrity.

The founder-facing companion is [`ANALYTICS_TELEMETRY_GUIDE.md`](../../guides/ANALYTICS_TELEMETRY_GUIDE.md).

## How to use it

| When | How this library helps |
|---|---|
| Planning | Define activation and the event vocabulary before code wires events. |
| Final check | Trace telemetry against requirements and user flows. |
| Code review | Check the event sink and code for drift, duplicate emitters, and broken exports. |
