# Admin Tooling Knowledge Library

> Deeper references for you and your AI on small pre-PMF admin surfaces. The goal is a protected founder control room, not an internal enterprise product.

The founder-facing companion is [`ADMIN_TOOLING_GUIDE.md`](../../guides/ADMIN_TOOLING_GUIDE.md).

## How to use it

| When | How this library helps |
|---|---|
| Planning the admin scope | Scope admin requirements to support, learning, and safety. |
| Building it | Server-side access checks, audit trails, and minimal admin APIs. |
| Security review | Privileged surfaces checked for access-control and abuse risks. |
| Final check | Admin actions traced, audit evidence present, normal users denied. |
